# 캐릭터 아트 방향 참고 자료

아홉 경계(The Ninefold Veil)의 현재 캐릭터·그래픽 아트 기준 소스입니다.
사용자는 이 폴더의 원문 다섯 개를 프로젝트 아트 지침으로 지정했으며,
이전 프로젝트 문서에 있던 아트 지침을 대체합니다. 원문에 미정으로 표시된 값은 계속 미정입니다.
원문 헤더의 “Draft for approval” 표기는 제공된 파일의 출처 메타데이터로 보존하며,
프로젝트 적용 상태는 사용자의 지정에 따라 현재 아트 지침입니다.

## 사용자 지정 주인공 시각 소스

- [`DAL_8_DIRECTION_VISUAL_REFERENCE.png`](DAL_8_DIRECTION_VISUAL_REFERENCE.png): 사용자가 주인공 제작의 시각 기준으로 지정한 달(Dal)의 8방향 시안. 이후 주인공 디자인을 만들 때 달의 외형·비율·무기 실루엣을 출발점으로 삼는다.
- 이 PNG는 방향별 단일 포즈 검토 시안이며, 확정된 애니메이션 시트나 게임용 아틀라스는 아니다. 각 방향의 프레임 경계와 애니메이션은 제작·검증이 필요하다.
- 이 소스 등록은 별도 인물의 배경, 성격, 능력, 관계를 확정하지 않는다.

## 핵심 요약

**승인된 방향: 2D 하이브리드**
- 캐릭터·일반 적: 도트(픽셀아트) 기반 스프라이트
- 배경: 깊이감 있는 레이어드 2D
- 전투 이펙트: 도트 형태 + 절제된 글로우/투명도
- 3D 파이프라인, 엔진 변경은 금지(별도 승인 필요). "웹툰 스타일"을 인게임 기본 스타일로 쓰지 않음.

**색상**: 남청색/차콜(기반) · 옥색/청록(초자연 에너지) · 주홍/절제된 진홍(인장·경고·포인트).
세력별 보조 색은 허용. 정확한 hex 값과 팔레트 수는 **미확정**. 색만으로 구분하지 않고 실루엣·문양·모양으로도 구분.

**카메라(v1.1)**: 각진 탑다운 쿼터뷰. 엄밀한 아이소메트릭은 아님. 캐릭터·적·바닥 표식·공격 예고가 같은 지면에 서 있어야 하고, 발 접점(ground anchor)이 프레임마다 안정적이어야 함. 사이드뷰 포즈, 정면 초상화, 얼굴·무기를 가리는 순수 위에서 내려다보기는 금지.

**방향(v1.1, 확정 아님)**: 첫 테스트는 위·아래·좌·우 4방향. 대각선 이동은 가장 가까운 4방향 스프라이트로 대체하고, 필요가 확인되면 대각선을 추가. 좌우 반전은 비대칭 요소(무기 쥔 손, 장식 등)가 틀어지지 않을 때만 허용. 코드가 4방향/8방향을 요구한다고 가정하지 않음.

**스프라이트**: 비례는 2.5~3등신에 제한하지 않으며 약 2등신도 허용(사용자 결정). 약 48×48 논리 픽셀은 *초기 참고값*일 뿐 확정 아님. 일반 적은 32~48 범위가 참고값. 일러스트를 축소하지 않고 게임 크기에 맞게 디테일 우선순위를 다시 설계.

**가독성 우선순위**: 보스 공격 예고/위험 구역 > 플레이어·회피·스킬 > 보조 이펙트·피격 파티클.

**4대 세력**: 저승사자(죽음·기록·권위) / 도깨비(강한 에너지·장난기) / 구미호(환상·우아함) / 산신(산·자연·수호).
고정 고정관념이 아니며, 개별 캐릭터의 세력·배경·능력을 임의로 만들지 않음.

**작업 순서**: 레퍼런스 영상·문서 검토 → 소규모 스타일 테스트 → 주인공 설정화 + 스프라이트 → 실제 전투 화면에서 가독성 테스트 → 픽셀 크기·팔레트·셰이딩·애니메이션 규칙 승인 → 동료·적·보스·배경·UI로 확장.

## 달(Dal) 확정 사항 (사용자 결정, 2026-10-28)
- 우선 제작할 주인공은 달. 캐릭터 선택창은 나중에 별도 제작.
- 로비/선택 화면에는 큰 일러스트, 인게임은 논리 48px 스프라이트를 쓴다(같은 디자인에서 파생).
- 방향은 **8방향**(달에 한함). 대각선도 직접 그린다. 방향 선택은 현재 코드와 같이 이동 방향 기준.
- 머리 장식(주홍 매듭과 술)은 **캐릭터 자신의 왼쪽(정면에서 볼 때 보는 사람 기준 오른쪽)에만** 둔다. 오른쪽을 보는 스프라이트는 왼쪽을 보는 것의 좌우 반전이 아니라 따로 그린다.
- 노출 수준, 2등신 비례, 팔레트는 현재 시안을 유지한다. 머리카락은 디테일을 해치지 않는 범위에서만 단순화한다. 단검은 캔버스 안에 들어오도록 길이만 줄인다.
- 인게임 스프라이트는 쿼터뷰 각도(위에서 약간 내려다봄)로 다시 그린다. 정면 시안을 그대로 쓰지 않는다.
- 보스: 06 아귀는 조선 맵의 중간·두 번째 보스(두 번째는 뿔과 부적 문양을 더해 모양으로 구분), 07 장군은 최종 보스. 도감용 고디테일본과 인게임 단순화본을 따로 만든다.

## 아직 미확정인 것 (스타일 테스트 후 결정)
- 정확한 픽셀 스케일, 외곽선 정책, 팔레트 크기, 프레임 수, 방향 수
- hex 색상 코드
- 로비/선택 화면 일러스트 방식(풀바디 일러스트 vs 고해상도 도트 초상)

달(Dal)의 8방향 시안은 주인공 디자인의 시각 기준으로 지정되었지만,
게임용 애니메이션의 방향 구성과 프레임 수는 아직 확정되지 않았다.

## 현재 프로젝트와 확인할 점
- 기존 주인공과 원혼은 검토했고, 별도의 수정 후보가 `art-assets/character-design-review-2026-10-28/`에 저장되어 있다. 후보는 사용자가 최종 승인하고 게임용 포맷으로 변환하기 전까지 런타임 에셋을 대체하지 않는다.
- 생성 도구는 사용자가 선택한다(ChatGPT ImageGen 또는 Higgsfield). Higgsfield처럼 크레딧이 소모되는 생성은 `CLAUDE.md`에 따라 예상 비용 확인과 사용자 명시 승인을 거친다.
