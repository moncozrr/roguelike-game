The Ninefold Veil — ground assets

Files:
- ground_base.png: 500x500 base ground crop
- ground_variant_*.png: 500x500 terrain variation crops
- overlay_*.png: overlay element crops with approximate transparency extracted from a checkerboard preview

Important:
These PNGs were extracted from a composite concept sheet, not exported as original isolated source layers.
The base/variant crops are useful prototypes but are not guaranteed to tile seamlessly.
Overlay transparency is approximate because the source sheet showed a checkerboard rather than true alpha.
For production, inspect edges and clean up overlays, and make the ground variants seamless before shipping.
