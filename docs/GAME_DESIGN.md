# 《아홉 경계》 (The Ninefold Veil) 개발팀 인수인계 문서

## 2D Top-Down Survival Action Roguelike RPG --- Vertical Slice Specification

-   문서 목적: 현재까지 합의한 게임 규칙을 개발 가능한 단위로 정리한다.
-   개발 환경: Windows 11, VS Code, Claude Code, JavaScript 기반 웹게임.
-   현재 목표: 빠르게 플레이 가능한 5분 프로토타입을 만든 뒤 테스트하고
    확장한다.
-   문서 규칙:
    -   **확정**: 사용자가 선택하거나 명시적으로 합의한 규칙.
    -   **미결정**: 아직 결정하지 않은 값. 개발자가 임의로 게임 기획으로
        확정하지 않는다.
    -   **제안/테스트값**: 프로토타입 테스트를 위해 임시로 사용할 수
        있지만, 실제 밸런스 확정값은 아니다.
    -   **향후 확장**: 이번 수직 슬라이스에는 구현하지 않는다.

# 1. 프로젝트 개요

## 1.1 게임 정체성

-   장르: 2D 탑다운 생존 액션 로그라이크 RPG.
-   핵심 차별점: 플레이어가 고정된 **경계(Boundary)** 안에서 강화 효과를
    얻고, 경계 안팎의 위치와 적의 이동을 활용해 전투한다.
-   전투는 자동 공격을 기본으로 하며 플레이어는 이동, 회피, 성장 선택,
    경계 내외 위치 선정에 집중한다.
-   핵심 성장 트랙은 서로 분리된다.
    1.  일반 레벨업: 무기 획득, 무기 강화, 경험치 자석 강화.
    2.  경계 강화: 중간 보스 처치 후 별도의 경계 강화 카드 선택.
-   스토리와 장기 수집 시스템은 중요한 확장 방향이지만, 첫 수직
    슬라이스에서는 핵심 전투 루프를 우선한다.

## 1.2 수직 슬라이스 목표

첫 번째 목표는 **5분 플레이 가능한 프로토타입**이다. 5분이 되었다고
강제로 종료하지 않는다. - 0:00 던전 진입. - 0:00--2:00 일반 적과 전투,
경험치 구슬 획득 및 레벨업. - 2:00 중간 보스 출현. - 중간 보스 처치 시
경계 강화 선택. - 3:00 두 번째 보스 출현. 중간 보스가 살아 있어도
예정대로 출현한다. 두 번째 보스를 처치해도 런은 끝나지 않는다. - 5:00
최종 보스 출현. 다른 보스의 생존 여부와 무관하게 예정대로 출현한다. -
5:00 이후에도 최종 보스가 살아 있으면 플레이를 계속한다. - 런은 최종
보스 처치(승리) 또는 플레이어 사망 시 종료한다.

## 1.3 개발 우선순위

1.  게임 루프, 이동, 카메라, 충돌.
2.  일반 적 생성 및 추적 AI.
3.  플레이어 피해 처리와 회피.
4.  자동 공격과 무기.
5.  경험치 구슬 및 레벨업.
6.  경계 시스템과 내구도.
7.  중간 보스 및 경계 강화 보상.
8.  최종 보스 출현 및 전투.
9.  UI, 입력, 시각 효과, 밸런스 테스트.
10. 최종 아트 교체가 쉬운 구조로 정리.

# 2. 확정된 핵심 게임 규칙

## 2.1 플레이어 이동과 카메라

-   플레이어는 자유 이동한다.
-   PC 기본 이동 입력은 WASD.
-   공격은 자동 공격이다. 기본 전투에서 마우스 조준은 요구하지 않는다.
-   카메라는 플레이어를 따라가며 플레이어를 화면 중앙 부근에 유지한다.
-   맵과 적은 카메라 이동에 따라 화면상 상대적으로 움직인다.
-   월드는 유한하지만, 플레이 중 맵 가장자리가 자주 보이지 않을 만큼
    넓게 만든다.
-   무한 월드 생성은 수직 슬라이스 범위가 아니다.
-   모바일 가상 조이스틱은 5분 수직 슬라이스 때는 후속 대응이었으나,
    2026-10-27 사용자 결정으로 로비 MVP 범위에 포함한다(가로 화면 기준,
    `docs/LOBBY_MVP_PLAN.md` 마일스톤 M9). PC 조작은 그대로 유지한다.

## 2.2 대시와 피격 보호

-   플레이어는 이동 중 대시할 수 있다.
-   대시 중 짧은 무적 시간을 제공한다.
-   대시 거리, 지속 시간, 쿨다운, 무적 시간의 정확한 값은
    **미결정**이다.
-   대시 무적과 피격 후 보호 시간은 서로 다른 시스템이다.
-   피해를 받은 뒤에는 짧은 피격 후 보호 시간이 있어 연속 접촉으로 즉시
    피해가 반복되지 않는다.
-   보호 시간 중에는 접촉 피해와 적 투사체 피해를 받지 않는다.
    세부적으로 공격 유형별 예외가 필요하면 추후 명시적으로 결정한다.

## 2.3 플레이어 사망

-   플레이어 HP가 0이 되면 즉시 게임 오버.
-   현재 수직 슬라이스에서는 부활 기능을 제공하지 않는다.

# 3. 경계 시스템

## 3.1 경계의 기본 구조

-   경계는 플레이어를 따라다니지 않는다.
-   경계는 월드 좌표에 고정된다.
-   경계 중심은 플레이어가 처음 던전에 진입한 시작 위치다.
-   경계 형태는 원형이다.
-   카메라가 플레이어를 따라가므로, 플레이어가 이동하면 경계는 화면에서
    상대적으로 움직인다.
-   기본 크기는 경계 안에서 기본 전투를 할 수 있지만, 플레이어가 안팎을
    오갈 수 있을 정도의 중간 크기다.
-   경계는 줄어들지 않는다. 기본 반경은 고정되고 강화 선택으로만 커질 수
    있다.
-   경계 밖에서는 경계 강화 효과를 받지 않지만, 경계 밖에 있다는
    이유만으로 HP가 감소하지 않는다.
-   경계 안에 진입할 때 긍정적인 시각 효과를 줄 수 있으나 플레이를
    가리지 않아야 한다. 세부 연출은 미결정이다.

## 3.2 경계 강화

-   경계 강화는 일반 레벨업과 별도의 성장 트랙이다.
-   중간 보스 처치 직후 경계 강화 보상 화면을 연다.
-   보상 선택 중 전투는 일시 정지한다.
-   경계 강화 카드 중 하나를 선택하면 효과를 적용하고 화면을 닫은 뒤
    전투를 재개한다.
-   각 보상 화면에는 유효한 강화 카드가 최대 3개 표시된다.
-   한 화면 안에서는 서로 다른 강화 옵션만 표시하며 중복 카드는 없다.
-   선택 가능한 옵션이 1\~2개만 남으면 해당 카드만 표시한다. 빈칸을
    채우기 위한 가짜 보상은 넣지 않는다.
-   최대 레벨에 도달한 강화는 후보에서 제외한다.
-   같은 강화는 서로 다른 보상 이벤트에서 다시 선택할 수 있으나, 해당
    강화의 최대 레벨 제한을 적용한다.
-   보상 후보의 가중치나 빌드 기반 추천은 미결정이다.

## 3.3 현재 경계 강화 후보

다음은 현재 합의된 후보 목록이다. 각 강화의 정확한 효과 수치와 최대
레벨은 별도 표기가 없는 한 미결정이다. 1. 경계 내부 HP 회복률 증가. 2.
경계 내구도 증가. 3. 경계 반경 증가. 4. 경계 내부 플레이어 공격력 증가.
5. 적 공격 속도 감소. 6. 적 공격력 감소.

### 반경 강화의 확정 수치

-   반경 강화는 최대 3레벨.
-   각 레벨은 **기본 반경의 10%**만큼 반경을 추가한다.
-   최대 반경은 기본 반경의 130%.
-   중심점은 계속 고정되며, 반경만 증가한다.

## 3.4 경계 내구도

-   경계 내구도는 방어막 내구도와 안정성 약화 효과를 결합한 시스템이다.
-   특정 적이 경계 내구도에 피해를 줄 수 있다. 구체적인 적 종류와
    공격량은 미결정이다.
-   경계 내구도가 감소하면 경계 버프가 약해진다.
-   경계 내구도가 최대치에서 10% 감소할 때마다 경계 버프 효과가 5%
    감소한다.
-   버프 감소는 최대 50%까지다.
-   경계는 내구도가 낮아져도 완전히 파괴되거나 사라지지 않는다.
-   경계에 피해가 들어오지 않는 동안, 회복이 켜져 있으면 최대 내구도의
    초당 5%를 회복한다.
-   0%에서 100%까지 회복하는 데 약 20초가 걸리는 규칙이다.
-   플레이어는 버튼으로 경계 회복 기능을 켜고 끌 수 있다.
-   회복 ON/OFF 버튼의 위치와 UI 표현은 미결정이다.

## 3.5 경계 버프 공유 규칙

-   경계 내부의 인간형 적과 보스는 전투 능력치 버프의 50%를 공유한다.
    예: 공격력 또는 공격 속도 버프.
-   플레이어의 HP 회복 효과는 적에게 공유되지 않는다.
-   비인간형 적은 경계 버프를 공유하지 않는다.
-   단순히 경계에 닿는 행위에는 특별한 효과가 없다.
-   따라서 인간형 보스를 경계 밖으로 유인해 버프 공유를 차단하는 전술이
    가능하다.

## 3.6 경계 관련 향후 기능

-   특정 건물을 파괴하면 평소보다 훨씬 큰 적 웨이브가 발생하고,
    플레이어가 경계 안으로 돌아와 싸우도록 유도하는 기능은 향후
    확장이다.
-   건물 파괴로 중간/최종 보스 능력치를 약화하는 기능도 향후 확장이다.
-   위 건물 시스템은 이번 수직 슬라이스에서 구현하지 않되, 향후 기획
    목록에 보존한다.

# 4. 전투 및 무기

## 4.1 자동 공격과 대상 선택

-   공격은 자동으로 실행된다.
-   기본 대상 선택 원칙은 가장 가까운 적이다.
-   원거리 투사체 무기는 사거리와 장애물을 고려해 공격 가능한 적을
    선택하는 방식으로 설계한다.
-   회전형 근접 무기는 플레이어 주변의 공격 범위에 들어온 적을 자동으로
    타격한다.
-   방향/부채꼴 근접 무기는 가장 가까운 적 방향을 향해 자동 공격한다.
-   각 무기의 구체적 피해량, 공격 간격, 사거리, 투사체 속도는
    미결정이다.
-   맵 장애물은 수직 슬라이스에서 최소화한다. 복잡한 장애물 및 투사체
    차단 규칙은 후속 결정이다.

## 4.2 무기 슬롯과 레벨

-   최대 무기 슬롯은 3개.
-   무기 종류별로 하나만 보유한다. 같은 무기를 새 무기 슬롯으로 중복
    획득할 수 없다.
-   보유한 무기가 레벨업 후보에 다시 나오면 새 무기 획득이 아니라 해당
    무기 강화 후보로 처리한다.
-   무기 최대 레벨은 5.
-   기본 강화는 주로 공격력 증가로 시작한다.
-   무기 진화 및 레벨 5 이후의 추가 진화는 이번 범위에서 제외한다.
-   무기 3개 슬롯이 모두 차 있으면 새 무기 획득 후보 대신 보유 무기 강화
    후보를 사용한다.
-   보유 무기 3개가 모두 레벨 5이고 경험치 자석도 최대 레벨이면, 선택
    화면을 열지 않고 미래 재화 시스템의 재화만 지급한다. 재화 종류와
    양은 미결정이다.

## 4.3 무기 예시(아직 확정 아님)

이전에 논의된 이름은 구현 확정 목록이 아니다. 필요하면 임시 프로토타입
무기로 활용할 수 있다. - 경계의 창: 직선 원거리 투사체. - 경계의 고리:
플레이어 주변 회전형 근접 공격. - 균열 베기: 가까운 방향의 부채꼴 근접
공격.

## 4.4 플레이어 피해 유형

-   플레이어는 적과 겹쳐 지나갈 수 있다. 적과 충돌해 이동이 막히지는
    않는다.
-   접촉 피해는 발생할 수 있으며, 피격 후 보호 시간 규칙을 따른다.
-   적 투사체는 기본적으로 한 번 명중하면 피해를 주고 사라진다.
-   기본 투사체는 관통하지 않고 지속 피해도 주지 않는다.
-   관통, 지속 피해, 유도 투사체는 특수 무기/적의 후속 기능이다.

# 5. 적 AI, 생성, 충돌

## 5.1 일반 적 생성

-   일반 적은 지속적으로 생성된다.
-   게임 시간이 1분 경과할 때마다 생성 빈도와 생성 그룹 크기가 각각
    기본값 대비 20%p씩 증가한다. 증가 방식은 복리 곱셈이 아니라 기본값
    대비 가산 방식이다.

  게임 시간     기본값 대비 생성 빈도/그룹 크기
  ----------- ---------------------------------
  0:00                                     100%
  1:00                                     120%
  2:00                                     140%
  3:00                                     160%
  4:00                                     180%
  5:00                                     200%

-   기본 생성 빈도와 기본 그룹 크기는 미결정이다.
-   소수 단위 그룹 크기의 반올림/누적 처리 방법은 구현 세부 사항이다.
-   일반 적은 화면 바깥에 생성되며 화면 가장자리 바깥의 추가 여유
    거리에서 등장한다. 정확한 거리 값은 미결정이다.
-   적은 기본적으로 플레이어를 향해 이동한다.

## 5.2 적 AI

-   기본 근접 적은 플레이어를 추적하고 접촉 시 피해를 준다.
-   기본 원거리 적도 우선 플레이어를 추적한다. 거리 유지 등 복잡한 AI는
    후속 범위다.
-   원거리 적은 발사 순간의 플레이어 위치를 향해 작은 구체 투사체를
    발사한다.
-   투사체는 발사 시 정해진 방향으로 직선 이동한다. 플레이어를 추적하지
    않는다.
-   특수 적과 보스는 이후 별도 행동 패턴을 추가할 수 있다.

## 5.3 적끼리의 충돌

-   플레이어와 적은 서로 통과할 수 있다.
-   적끼리는 서로 겹치지 않으며 밀어내는 방식으로 분리한다.
-   적의 밀어내기 처리는 적이 지나치게 떨리거나 뭉치는 현상이 없는지
    테스트한다.

# 6. 경험치 및 일반 레벨업

## 6.1 경험치 구슬

-   적을 처치하면 경험치 구슬이 생성된다. 경계 안/밖 모두 동일하다.
-   경험치 구슬은 플레이어가 획득할 때까지 월드에 남는다. 시간이 지나도
    사라지지 않는다.
-   기본 획득 범위는 작다.
-   경험치 자석 강화는 획득 범위를 넓힌다.

## 6.2 경험치 자석

-   일반 레벨업 후보 중 하나다.
-   최대 레벨은 3.
-   각 레벨은 기본 획득 반경의 10%만큼 추가한다.
-   최대 획득 반경은 기본 반경의 130%.
-   최대 레벨이면 후보에서 제외한다.
-   무기 슬롯을 차지하지 않는다.

## 6.3 일반 레벨업 보상 후보

일반 레벨업 화면에는 현재 상태에 따라 유효한 보상 중 최대 3개를 무작위로
표시한다. - 새 무기 획득. - 보유 무기 강화. - 경험치 자석 강화. - 경계
강화는 일반 레벨업 후보에 포함하지 않는다. - 중복되거나 선택 불가능한
후보는 표시하지 않는다. - 후보가 1\~2개면 유효한 후보만 표시한다. - 선택
가능한 후보가 하나도 없으면 레벨업 선택 화면을 열지 않고 미래 재화
시스템의 재화만 지급한다. - XP 요구량과 레벨업 성장 곡선은 간단한 테스트
값으로 시작하며, 정확한 곡선은 플레이 테스트 후 조정한다. - 5분 동안
발생해야 하는 레벨업 횟수는 미결정이다.

## 6.4 연속 레벨업

-   한 번에 여러 레벨을 올릴 경험치가 쌓였더라도 보상은 한 화면씩 순차
    처리한다.
-   각 화면에서 하나를 선택해야 다음 화면으로 넘어간다.
-   연속 레벨업이 모두 처리될 때까지 전투는 정지 상태를 유지한다.
-   각 레벨업 화면이 열릴 때마다 후보를 새로 무작위 선정한다.
-   후보 선정 시 직전 선택으로 바뀐 현재 무기 보유량/레벨과 자석 레벨을
    반영한다.
-   무기 강화는 서로 다른 레벨업 화면에서 연속으로 선택할 수 있다. 단,
    무기 최대 레벨 5를 넘을 수 없다.
-   새 무기는 종류별로 한 개만 보유한다.
-   자석은 최대 레벨 3까지다.

# 7. 중간 보스, 두 번째 보스, 최종 보스

## 7.1 시간 기반 출현

-   중간 보스는 게임 시작 후 2:00에 출현한다.
-   두 번째 보스는 게임 시작 후 3:00에 출현한다. 처치해도 런은 끝나지
    않으며 보상 화면도 열지 않는다(경험치 구슬만 떨어뜨린다).
-   최종 보스는 게임 시작 후 5:00에 출현한다. 이 보스를 처치하면 런이
    승리로 끝난다.
-   두 번째 보스와 최종 보스의 출현은 다른 보스의 처치 여부와 무관하다.
    다른 보스가 살아 있어도 예정대로 출현한다.
-   5:00에 최종 보스가 나오며, 최종 보스를 처치하지 못해도 런은 자동으로
    종료되지 않는다. 최종 보스가 살아 있다면 5:00 이후에도 전투가
    계속된다.
-   (변경 이력, 2026-10-26 사용자 결정: 이전 기획은 3:00 최종 보스였다.
    3:00 보스를 두 번째 보스로 바꾸고 최종 보스를 5:00으로 옮겼다.)

## 7.2 중간 보스 처치 보상

-   중간 보스를 처치하면 즉시 경계 강화 보상 화면을 연다.
-   보상 화면이 열린 동안 적 이동, 공격, 투사체 등 전투는 정지한다.
-   하나를 선택하면 효과를 적용하고 전투를 재개한다.
-   현재 수직 슬라이스에서는 건물 파괴 보상은 구현하지 않는다.

## 7.3 보스 세부 사항

-   보스와 정예 같은 특수 적은 플레이어에게서 800px 떨어진 화면 밖에서
    출현한다. 보스 속도 80에서 약 5초 안에 화면에 들어오도록 한 값이며,
    화면이 더 크면 화면 밖이 되도록 거리가 늘어난다. 월드 가장자리에서는
    알맞은 다른 방향을 고른다. 일반 적의 출현 위치 규칙은 이와 별개다.
-   보스의 이름, 외형, HP, 공격 패턴, 피해량, 페이즈 수는 미결정이다.
-   보스가 경계 안에 있을 때 인간형 보스라면 경계 버프의 50%를 공유한다.
    보스가 경계 밖에 있으면 해당 경계 내부 버프 공유를 받지 않는다.

# 8. 보상 화면 UI --- 확정 규칙

## 8.1 두 화면의 공통 UI

일반 레벨업과 경계 강화는 같은 카드형 UI 구조를 사용하되, 보상 데이터와
후보 생성 로직은 분리한다. - 최대 3장의 카드를 화면 중앙에 가로로
배치한다. - 카드가 1\~2개만 유효하면 그 카드만 표시한다. - 카드에는
**이름 + 효과 수치 + 짧은 설명**을 표시한다. - 보상 화면 상단에 제목을
표시한다. - 일반 레벨업: `LEVEL UP` - 경계 강화: `BOUNDARY UPGRADE` -
부제는 초기 구현에서 표시하지 않는다. 테스트 후 필요하면 추가한다. -
게임 배경을 유지하면서 반투명한 어두운 오버레이를 적용한다. - 화면이
열리면 카드가 즉시 나타난다. 등장 애니메이션은 초기 구현에서 제외한다. -
카드의 모서리, 최종 테두리 스타일, 배경색은 최종 아트 적용 시 결정한다.
초기에는 단순한 기본 사각형/배경/테두리로 시작한다. - 카드 크기는 화면에
따라 조절하되 최소·최대 크기를 제한한다. 구체적 픽셀 값은 플레이 테스트
후 결정한다. - 카드 배치는 무작위 후보를 선택한 뒤 화면상의 카드
순서/위치도 무작위로 섞는다. 숫자 키는 최종적으로 화면에서 왼쪽부터
배치된 카드 위치를 기준으로 한다.

## 8.2 카드 선택

-   카드의 어느 곳을 클릭해도 해당 보상을 선택한다.
-   별도 확인 버튼은 없다.
-   취소 버튼은 없다. 반드시 유효한 보상 하나를 선택한다.
-   선택 시 선택 카드가 짧게 빛나거나 살짝 확대되는 강조 효과를 준다.
-   선택 효과 중 중복 입력으로 보상이 여러 번 적용되지 않도록 잠금
    처리한다.
-   선택한 보상 효과를 한 번 적용하고 화면을 닫은 뒤 전투를 재개한다.
-   선택 중에는 전투가 일시 정지한다.

## 8.3 키보드 입력

-   `1`, `2`, `3` 키는 화면에서 왼쪽부터 배치된 첫 번째, 두 번째, 세
    번째 카드에 대응한다.
-   해당 숫자를 누르면 카드가 즉시 선택된다.
-   마우스 클릭도 동일하게 즉시 선택한다.
-   화면에 없는 카드에 대응하는 숫자는 무시한다.
-   숫자 단축키는 보상 화면이 열려 있을 때만 작동한다.
-   숫자 입력 후 Enter를 추가로 요구하지 않는다.

## 8.4 연속 레벨업 화면

-   한 레벨업의 선택 후 다음 레벨업이 남아 있다면 새 보상 화면을 연다.
-   다음 후보는 현재 상태를 기준으로 새로 추첨한다.
-   연속 레벨업 중에는 전투를 중간에 재개하지 않는다.

## 8.5 보상 카드의 효과 수치

-   카드 표시 규칙은 확정됐지만, 모든 강화의 정확한 수치가 확정된 것은
    아니다.
-   개발 중 임시 수치를 사용할 경우 코드/데이터에서 쉽게 조정 가능하도록
    분리한다.
-   문서의 예시 수치를 실제 밸런스 확정값으로 취급하지 않는다.

# 9. 게임 시간 및 밸런스 테스트

## 9.1 시간 계획

-   첫 프로토타입: 5분 테스트 런.
-   다음 목표: 10분 플레이.
-   이후 목표: 15분 플레이.
-   위 시간은 개발 단계별 목표이며, 5분 이후 강제 종료를 의미하지
    않는다.

## 9.2 시간 기반 적 생성

기본값 대비 가산 증가: - 0분: 100% - 1분: 120% - 2분: 140% - 3분: 160% -
4분: 180% - 5분: 200%

정확한 초당 생성량과 한 그룹의 적 수는 미결정이다. 우선 데이터 설정으로
분리해 플레이 테스트에서 조정한다.

## 9.3 미결정 밸런스 항목

다음 수치는 아직 기획에서 확정하지 않았다. - 플레이어 최대 HP, 이동
속도, 기본 회복량. - 대시 거리/시간/쿨다운/무적 시간. - 피격 후 보호
시간. - 기본 경계 반경 및 최대 내구도. - 경계 내구도 피해를 주는 적
종류와 피해량. - 각 경계 강화의 효과 수치와 대부분의 최대 레벨. - 기본
적 생성 빈도와 그룹 크기. - 적 HP, 이동 속도, 접촉 피해, 투사체
피해/속도. - 무기 피해, 사거리, 쿨다운, 투사체 속도. - XP 구슬의
경험치량, 레벨별 요구 경험치. - 중간/두 번째/최종 보스의 HP와 공격 패턴. -
카드 크기의 실제 픽셀 값 및 오버레이 투명도. - 미래 재화의 이름과
지급량.

이 값들은 테스트가 가능한 최소값을 임시로 설정할 수 있으나, 임시값임을
명시하고 나중에 조정할 수 있어야 한다.

# 10. 구현 범위와 향후 확장 분리

## 10.1 이번 수직 슬라이스에 포함

-   플레이어 추적 카메라.

-   월드 좌표에 고정된 원형 경계.
-   경계 내부/외부 효과 적용.
-   경계 내구도, 버프 약화, 회복 ON/OFF.
-   기본 적 생성 및 추적.
-   근접 적 접촉 피해.
-   원거리 적의 직선 투사체.
-   적끼리 밀어내기, 플레이어와 적은 통과.
-   자동 공격.
-   최대 3개 무기, 무기 레벨 최대 5.
-   경험치 구슬과 자석 강화.
-   일반 레벨업 보상 카드.
-   2:00 중간 보스 출현과 처치 후 경계 강화 선택.
-   3:00 두 번째 보스 출현, 5:00 최종 보스 출현.
-   게임 오버.
-   보상 화면 일시 정지, 카드 선택, 숫자 키 단축키.
-   간단한 시각 효과와 테스트 가능한 기본 그래픽.

## 10.2 이번 수직 슬라이스에서 제외

-   건물 파괴와 특수 대규모 웨이브.
-   건물 파괴를 통한 보스 약화.
-   무기 진화.
-   복잡한 원거리 적 거리 유지 AI.
-   유도 투사체, 관통, 지속 피해 등 특수 공격.
-   무한 월드 생성.
-   (모바일 조작 완성: 5분 수직 슬라이스에서는 제외였으나 2026-10-27
    사용자 결정으로 로비 MVP 범위로 이동. `docs/LOBBY_MVP_PLAN.md` 참고.)
-   동료 수집/편성/성장/성급 진화.
-   (몬스터 이름 해독과 도감 영구 성장: 수직 슬라이스 제외 항목이었으나
    2026-10-27 사용자 결정으로 로비 MVP에 도감 기본형이 포함된다.
    `docs/LOBBY_MVP_PLAN.md` 참고. 이름 해독의 상세 확장은 여전히 후속.)

## 10.3 향후 확장 백로그

세계관 자료에 등장하는 장기 기능은 다음 단계에서 재검토한다. 1. 건물
파괴와 특수 적 웨이브. 2. 건물 파괴를 통한 보스 능력치 약화. 3.
저승사자·도깨비·구미호·산신 계열 동료 수집 및 최대 4명 편성. 4. 동료
레벨/성급 진화 및 공격 패턴 해금. 5. 몬스터 이름 해독, 도감, 이름 완성
보상. 6. 서로 다른 세계가 무작위로 겹치는 무한 콘텐츠. 7. 아홉 경계의
세계관 및 장기 스토리. 8. 최종 아트 및 스프라이트 애니메이션 적용.

# 11. 아트 및 그래픽 방향

기존 아트 방향 문서 기준: - 한국 신화에서 영감을 받은 다크 판타지. -
캐릭터 선택/로비용은 세련된 2D 애니메이션·한국 웹툰풍 일러스트. - 인게임
캐릭터는 약 2.5\~3등신의 단순화된 스프라이트. - 인게임 스프라이트는 약
48×48 논리 픽셀을 초기 참고값으로 삼되, 무기/머리카락 등 실루엣 확장은
허용한다. - 머리 모양, 의상 실루엣, 무기, 진영 상징을 유지해 큰
일러스트와 인게임 스프라이트가 같은 캐릭터로 인식되어야 한다. - 공통
팔레트: 블루 블랙/차콜, 옥색/차분한 청록, 주홍/절제된 진홍. - 4개 주요
진영의 시각적 구분: - 저승사자: 죽음, 통로, 기록, 영적 권위. - 도깨비:
대담한 에너지, 초자연적 힘. - 구미호: 환영, 우아함, 여우 상징, 지능. -
산신: 산, 자연, 수호, 고대의 권위. - 색상만으로 캐릭터를 구분하지 않고
실루엣과 상징을 함께 사용한다. - 2D 에셋 중심으로 제작하며, 배경 투명화
및 애니메이션 프레임 제작이 가능하도록 한다. - 캐릭터 장비 업그레이드에
따른 외형 변경은 현재 범위에 포함하지 않는다. - 최종 아트가 제공되면
UI와 캐릭터 에셋을 교체할 수 있도록 로직과 그래픽을 분리한다.

# 12. 단계별 개발 계획

각 단계는 구현 → 실행 → 검수 → 사용자 확인 순서로 진행한다. 한 단계를
검수하기 전에 다음 단계로 넘어가지 않는다.

## 단계 0 --- 프로젝트 상태 확인 및 안전장치

작업: 1. 현재 저장소와 파일 구조를 확인한다. 2. 프로젝트가 이미
시작되었다면 기존 구조를 존중하고, 불필요하게 새 프로젝트로 덮어쓰지
않는다. 3. Git 상태를 확인하고 현재 작동 버전을 커밋하거나 백업한다. 4.
현재 실행/빌드 명령어를 확인한다. 5. 기술 스택을 확인한다. 기존
프로젝트가 있다면 임의로 프레임워크를 바꾸지 않는다.

완료 조건: - 프로젝트 실행 방법을 확인했다. - 변경 전 기준 버전을 복구할
수 있다. - 현재 파일 구조와 실행 명령이 문서화됐다.

## 단계 1 --- 최소 게임 화면과 시간 루프

작업: 1. 게임 화면과 업데이트 루프를 만든다. 2. 게임 시간 표시를 만든다.
3. 게임 시작, 실행, 일시 정지, 게임 오버 상태를 구분한다. 4.
테스트용으로 2:00/3:00/5:00 이벤트 타이머를 확인할 수 있게 한다.

완료 조건: - 게임 시간이 정상적으로 증가한다. - 일시 정지 중 게임 시간과
게임 로직이 멈춘다. - 게임 오버 후 전투 업데이트가 계속되지 않는다.

## 단계 2 --- 플레이어 이동과 카메라

작업: 1. WASD 이동을 구현한다. 2. 월드 좌표와 화면 좌표를 분리한다. 3.
카메라가 플레이어를 따라가도록 한다. 4. 플레이어 시작 위치를 기록한다.

완료 조건: - 플레이어가 8방향으로 움직인다. - 카메라 이동 시 플레이어가
화면 중앙 부근에 유지된다. - 월드 좌표 기반 오브젝트 위치가 카메라에
따라 일관되게 보인다.

## 단계 3 --- 원형 경계 기본형

작업: 1. 시작 위치에 경계 중심을 고정한다. 2. 원형 경계 시각화를 만든다.
3. 플레이어가 경계 안/밖인지 판정한다. 4. 경계 밖에 있다는 이유만으로
피해를 받지 않는지 확인한다. 5. 카메라 이동에도 경계가 월드에 고정되어
보이는지 확인한다.

완료 조건: - 경계는 플레이어를 따라다니지 않는다. - 경계 중심은 시작
위치에 남는다. - 플레이어가 경계를 자유롭게 드나든다.

## 단계 4 --- 적 생성, 추적, 충돌

작업: 1. 화면 바깥 버퍼 영역에서 일반 적을 생성한다. 2. 기본 적은
플레이어를 향해 이동한다. 3. 적끼리 밀어내는 처리를 추가한다. 4.
플레이어는 적을 통과할 수 있도록 한다. 5. 시간에 따른 생성 빈도/그룹
크기 배수를 적용한다.

완료 조건: - 적이 화면 바깥에서 생성되어 플레이어에게 접근한다. - 적끼리
겹침을 줄이며 서로 밀어낸다. - 플레이어가 적 사이를 통과한다. - 생성
배수는 매 분 기본값 대비 20%p씩 증가한다.

## 단계 5 --- 플레이어 HP, 접촉 피해, 대시

작업: 1. 플레이어 HP와 피해 처리를 만든다. 2. 접촉 피해를 구현한다. 3.
피격 후 보호 타이머를 만든다. 4. 대시와 대시 무적을 별도로 구현한다. 5.
테스트 가능한 임시 수치는 설정 파일로 분리한다.

완료 조건: - 보호 시간 동안 접촉 피해가 반복 적용되지 않는다. - 대시
무적과 피격 후 보호가 별개로 작동한다. - HP 0에서 게임 오버가 발생한다.

## 단계 6 --- 자동 공격과 기본 무기

작업: 1. 공통 무기 인터페이스/데이터 구조를 만든다. 2. 가장 가까운 적을
찾는 기본 대상 선택을 만든다. 3. 최소 한 개의 원거리 투사체 무기를
구현한다. 4. 최소 한 개의 근접/범위 공격을 구현한다. 5. 무기 슬롯 3개와
레벨 최대 5를 적용한다.

완료 조건: - 공격은 자동으로 실행된다. - 대상 선택이 안정적이다. - 무기
종류별로 하나만 보유한다. - 무기 레벨은 5를 넘지 않는다.

## 단계 7 --- 원거리 적 투사체

작업: 1. 원거리 적이 발사 시점의 플레이어 위치를 향해 조준한다. 2.
투사체를 직선으로 이동시킨다. 3. 명중 시 한 번 피해를 주고 제거한다. 4.
기본 투사체에는 유도/관통/지속 피해를 넣지 않는다.

완료 조건: - 발사 후 투사체가 플레이어를 계속 추적하지 않는다. - 투사체
하나가 여러 번 피해를 주지 않는다.

## 단계 8 --- 경험치 구슬과 레벨업

작업: 1. 적 처치 시 경험치 구슬을 생성한다. 2. 구슬은 획득될 때까지 남아
있게 한다. 3. 플레이어가 구슬을 획득하면 XP가 증가한다. 4. 레벨업 조건을
검사한다. 5. 경험치 자석 반경 강화(최대 3레벨)를 구현한다. 6. 무기
획득/강화/자석 강화 후보를 생성한다.

완료 조건: - 적 처치와 경험치 획득이 연결된다. - XP가 충분하면 레벨업
화면이 열린다. - 불가능한 보상과 최대 레벨 보상이 후보에서 제외된다. -
후보가 부족하면 유효한 카드만 표시한다.

## 단계 9 --- 공통 보상 카드 UI

작업: 1. 일반 레벨업/경계 강화가 재사용할 수 있는 카드 UI를 만든다. 2.
제목, 이름, 효과 수치, 짧은 설명을 표시한다. 3. 화면 중앙 가로 배치와
최소/최대 크기 제한을 적용한다. 4. 배경에 반투명 어두운 오버레이를
적용한다. 5. 등장 애니메이션 없이 즉시 표시한다. 6. 카드 클릭 및 1/2/3
숫자 입력을 지원한다. 7. 선택 카드에 짧은 강조 효과를 적용한다. 8. 선택
후 중복 입력을 막는다. 9. 선택 화면에서는 게임 시간을 포함해 전투를
정지한다.

완료 조건: - 마우스 클릭과 숫자 입력이 같은 보상을 선택한다. - 카드가
1\~2개면 없는 카드 번호 입력은 무시된다. - 보상은 한 번만 적용된다. -
선택 후 화면이 닫히고 게임이 재개된다. - 카드 디자인은 최종 아트로
교체할 수 있다.

## 단계 10 --- 경계 내구도와 강화 효과

작업: 1. 경계 최대 내구도와 현재 내구도를 만든다. 2. 회복 ON/OFF 입력을
만든다. 3. 피해가 들어오지 않을 때 초당 최대 내구도의 5% 회복한다. 4.
내구도 감소에 따른 버프 약화 규칙을 구현한다. 5. 경계 강화 후보를
구현한다. 6. 반경 강화는 기본 반경의 10%씩 최대 3레벨로 구현한다. 7.
경계 내부에서만 버프가 적용되도록 한다. 8. 인간형 적/보스의 50% 버프
공유를 적용한다. 비인간형 적은 공유하지 않는다.

완료 조건: - 경계는 파괴되지 않는다. - 10% 내구도 손실당 버프가 5%
약화되고 최대 약화는 50%다. - 회복은 토글로 켜고 끌 수 있다. - 경계
밖에서는 경계 버프가 적용되지 않는다. - 경계 중심은 고정되고 반경만
증가한다.

## 단계 11 --- 중간 보스

작업: 1. 2:00에 중간 보스를 출현시킨다. 2. 보스 전투를 구현한다. 3. 처치
시 즉시 경계 강화 보상 화면을 연다. 4. 선택 중 전투를 정지한다. 5. 선택
후 전투를 재개한다.

완료 조건: - 중간 보스가 2:00에 출현한다. - 처치 직후 경계 강화 화면이
열린다. - 경계 강화는 일반 레벨업 후보에 섞이지 않는다.

## 단계 12 --- 최종 보스와 런 종료

작업: 1. 3:00에 두 번째 보스를, 5:00에 최종 보스를 출현시킨다. 2. 다른
보스의 생존 여부와 독립적으로 출현시킨다. 3. 두 보스의 HP/공격을 테스트
가능한 임시 데이터로 분리한다. 4. 최종 보스 처치 시 승리 상태를
만든다(두 번째 보스 처치는 승리가 아니다). 5. 플레이어 사망 시 게임 오버
상태를 만든다. 6. 최종 보스가 살아 있으면 5:00 이후에도 플레이를
계속한다.

완료 조건: - 두 번째 보스가 3:00에, 최종 보스가 5:00에 출현한다. -
두 번째 보스를 처치해도 런이 끝나지 않는다. - 최종 보스를 처치하면
승리로 런이 종료된다. - 최종 보스가 살아 있어도 5:00에 자동 종료되지
않는다. - 플레이어 사망으로 런이 종료된다.

## 단계 13 --- 5분 수직 슬라이스 검수

검수 항목: - 시작부터 5분 이상 플레이할 수 있다. - 적 생성 증가가
시간표대로 작동한다. - 플레이어 이동/대시/피해/보호 시간이 작동한다. -
자동 공격이 작동한다. - 경험치와 레벨업이 작동한다. - 연속 레벨업은
순차적으로 처리되며, 중간에 전투가 재개되지 않는다. - 중간 보스는 2:00,
두 번째 보스는 3:00, 최종 보스는 5:00에 출현한다. - 경계 강화 보상은 중간 보스 처치 직후
열린다. - 경계 내구도와 버프 약화/회복이 작동한다. - 보상 카드 입력과
중복 방지가 작동한다. - 5:00 이후에도 최종 보스가 살아 있으면
전투가 계속된다. - 최종 보스를 처치하면 승리한다. - 모든 임시 밸런스 값은 나중에 쉽게 조정할 수 있다.

# 13. 코드 구조 권장사항

현재 저장소에 이미 구조가 있다면 기존 구조를 우선한다. 새 프로젝트를
시작하는 경우에만 다음과 같은 역할 분리를 고려한다.

-   `gameLoop`: 업데이트/렌더 루프와 게임 시간.
-   `gameState`: 준비, 전투, 보상 선택, 승리, 게임 오버.
-   `player`: 이동, HP, 대시, 피격 보호.
-   `camera`: 플레이어 추적 및 월드-화면 좌표 변환.
-   `boundary`: 중심/반경/내구도/회복/내부 판정/버프.
-   `enemy`: 공통 적 데이터와 AI.
-   `spawner`: 시간에 따른 생성 빈도 및 그룹 크기.
-   `projectile`: 발사, 직선 이동, 명중/제거.
-   `weapon`: 무기 정의, 대상 선택, 공격 실행, 레벨.
-   `experience`: XP 구슬, 수집, 레벨업.
-   `rewardSystem`: 유효 후보 선정 및 보상 적용.
-   `rewardUI`: 카드 표시, 클릭/숫자 입력, 선택 강조.
-   `boss`: 시간 기반 출현과 보스 행동.
-   `config`: 밸런스 테스트 값.

필수 원칙: 1. 밸런스 숫자를 여러 코드 위치에 하드코딩하지 않는다. 2. UI
렌더링과 보상 적용 로직을 분리한다. 3. 월드 좌표와 화면 좌표를 혼용하지
않는다. 4. 게임 정지 상태에서는 전투 AI, 투사체, 타이머 등 정지 대상
업데이트가 진행되지 않게 한다. 5. 선택 이벤트가 두 번 실행되지 않도록
보상 화면에 선택 처리 상태를 둔다. 6. 각 단계가 완료될 때 실행
테스트하고, 작동하는 상태를 Git 커밋으로 보존한다. 7. 한 번에 많은
기능을 추가하지 말고, 한 단계씩 구현 후 검수한다.

# 14. 구현 전에 확인할 미결정 항목

아래 항목은 현재 기획에서 확정되지 않았으므로 개발자가 임의로 최종
규칙으로 만들면 안 된다.

1.  플레이어 기본 HP, 이동 속도, 대시 수치.
2.  피격 후 보호 시간과 대시 무적 시간.
3.  기본 경계 반경/최대 내구도.
4.  경계 내구도에 피해를 주는 적과 공격량.
5.  경계 강화별 효과 수치 및 대부분의 최대 레벨.
6.  기본 적 생성 빈도, 그룹 크기, 화면 바깥 생성 거리.
7.  적 HP, 이동 속도, 피해량, 투사체 속도.
8.  무기 피해량, 공격 주기, 사거리, 투사체 속도.
9.  경험치 구슬 경험치량, XP 곡선, 목표 레벨업 횟수.
10. 중간 보스/두 번째 보스/최종 보스의 외형, HP, 패턴.
11. 미래 재화의 이름, 획득량, 사용처.
12. 카드 크기, 오버레이 투명도, 선택 강조 효과의 정확한 시간.
13. UI 최종 언어, 폰트, 테두리, 배경색, 아트.
14. 플레이어/적 애니메이션 프레임 수와 이동/공격/피격/사망 애니메이션.
15. 정확한 기술 스택은 기존 저장소를 확인한 뒤 유지/결정한다.

# 15. 개발팀 작업 규칙

1.  **한 단계씩 진행한다.** 현재 단계의 완료 조건을 통과하기 전에는 다음
    단계로 넘어가지 않는다.
2.  **질문을 먼저 한다.** 요구사항이 모호하거나 충돌할 경우 추측으로
    확정하지 말고 사용자에게 질문한다.
3.  **확정과 임시를 구분한다.** 임시 밸런스 값은 설정 파일에 분리하고
    테스트값임을 표시한다.
4.  **기존 작업을 보존한다.** 기존 코드 구조, Git 변경사항, 작동하는
    기능을 확인하지 않고 대규모 덮어쓰기를 하지 않는다.
5.  **각 단계에서 검수한다.** 무엇을 변경했는지, 어떻게 실행하는지, 어떤
    테스트를 통과했는지 짧게 보고한다.
6.  **사용자 확인을 기다린다.** 한 단계의 결과를 보여준 뒤 질문이나 막힌
    부분이 있는지 확인하고 다음 단계로 진행한다.
7.  **아트는 교체 가능하게 만든다.** 임시 사각형과 기본 스프라이트를
    써도 로직은 최종 아트에 종속되지 않게 한다.
8.  **핵심 루프가 우선이다.** 동료, 도감, 스토리, 건물 파괴, 무한 복합
    영역 등은 수직 슬라이스 완성 이후 재검토한다.

# 16. 첫 개발 세션의 시작 지시

개발을 시작할 때 Claude Code에 아래 지시를 전달한다.

> 이 문서는 《아홉 경계》 2D 탑다운 생존 액션 로그라이크의 현재 기획
> 기준이다. 먼저 현재 저장소와 파일 구조, 실행 명령, Git 상태를
> 확인하라. 파일을 수정하기 전에 현재 프로젝트 상태를 요약하고, 1단계
> 구현 계획을 제안하라. 확정 규칙과 미결정 사항을 구분하고, 미결정
> 밸런스 값은 임시 설정값으로 분리하라. 한 번에 전체 게임을 만들지 말고,
> 각 단계의 완료 조건을 통과한 뒤 사용자에게 결과와 테스트 방법을
> 보고하고 다음 단계로 넘어가라. 기존 작동 코드를 확인하지 않고 덮어쓰지
> 말라.

# 17. 별도 세계관 자료와의 관계

프로젝트에 별도 세계관/캐릭터 자료가 존재한다. 해당 자료는 장기 콘텐츠와
아트 방향에 참고하되, 이 문서의 수직 슬라이스 구현 범위보다 우선하지
않는다.

세계관 문서에 포함된 장기 시스템 예시: - 몬스터 이름 해독: 일반 몬스터는
누적 처치로 이름 글자를 공개하고, 보스는 반복 도전/처치로 이름을
해독한다. - 동료 수집: 저승사자·도깨비·구미호·산신 계열 동료를
성장시키고 최대 4명 편성하는 장기 시스템. - 복합 영역 무한 콘텐츠: 여러
세계의 환경과 적이 랜덤하게 겹치는 확장 콘텐츠. - 아홉 경계 세계관:
이름, 형상, 기운, 공간, 시간, 생사, 기억, 통로, 분리의 경계와 장기
스토리.

이 시스템들의 상세 수치와 보상 규칙은 세계관 자료에서 제안된 내용일 수
있으며, 현재 수직 슬라이스에서 구현할 기능으로 자동 승격하지 않는다.
별도 기획 단계에서 다시 검토하고, 사용자 승인 후 구현 범위에 포함한다.
