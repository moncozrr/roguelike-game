# 아홉 경계 (The Ninefold Veil)

2D 탑다운 생존 액션 로그라이크 RPG. JavaScript + HTML + CSS + Vite 기반의 브라우저 게임입니다.

- 게임 이름: 한글 **아홉 경계**, 영문 **The Ninefold Veil**. 화면에 보이는 제목은 "아홉 경계"입니다.
  이름을 바꿀 때는 **두 곳**을 고칩니다: `src/config.js`의 `GAME_TITLE`(화면 제목과 탭 제목),
  `index.html`의 `<title>`(JS가 실행되기 전에 잠깐 보이는 폴백).
- 현재 목표: 기획 문서에 정의된 **5분 수직 슬라이스**.

## 실행 방법

```bash
npm install        # 처음 한 번, 의존성 설치
npm run dev        # 개발 서버 실행 (브라우저에서 표시된 주소로 접속)
npm run build      # dist/ 폴더에 배포용 빌드 생성
npm run preview    # 빌드 결과를 로컬에서 확인
npm test           # 자동 테스트 실행(Node 내장 테스트 러너, 추가 설치 없음)
```

## 현재 구현된 기능

- WASD / 방향키 8방향 이동 (대각선 속도 정규화)
- Space 대시 (이동 중이 아니면 마지막 이동 방향, 쿨다운 있음)
- 스프라이트 걷기/대시 애니메이션 (불러오기 실패 시 원형으로 대체 표시)
- 창 크기 변경 대응
- 게임 상태와 게임 시간(`m:ss` 표시), 120초(중간 보스)/180초(두 번째 보스)/300초(최종 보스) 이벤트 알림과 보스 출현(단계 11, 12)

- 월드 좌표계(임시 4000 × 4000px)와 플레이어 추적 카메라
  - 플레이어 위치는 월드 좌표이고 월드 밖으로 나가지 않습니다(대시 포함).
  - 월드 중앙 부근에서는 플레이어가 화면 중앙에 있고, 가장자리에서는 카메라가 월드 밖을 보여 주지 않도록 멈춥니다.
  - 창 크기가 바뀌어도 플레이어의 월드 좌표는 그대로이고 카메라만 다시 계산됩니다.
  - 바닥 격자는 월드에 고정되어 카메라와 함께 움직이고, 비네트/HUD/오버레이는 화면에 고정됩니다.
  - 플레이어 시작 위치(월드 중앙)를 기록해 둡니다(단계 3의 경계 중심으로 사용 예정).
- 개발 모드 전용 검증 표식(월드 중앙 십자, 월드 가장자리 테두리). 배포 빌드에서는 표시되지 않습니다.
  검증이 끝나면 제거할 예정이며 `drawWorldMarkers`에 모여 있습니다.
- 원형 경계 (단계 3)
  - 중심은 플레이어가 시작한 위치 `(2000, 2000)`에 고정되고 플레이어를 따라다니지 않습니다(새 런을 시작할 때 다시 생성).
  - 기본 반경 300px(임시). 청록색 테두리와 옅은 내부 채움으로 월드 레이어에 그립니다.
  - 플레이어 중심점과 경계 중심의 거리가 반경 이하면 내부(경계선 위 포함), 초과하면 외부입니다.
  - 경계 안에서는 경계 버프(임시: 플레이어 공격력 +50%)를 받고 밖에서는 받지 않습니다. 내구도, 회복(R 키), 버프 약화는 단계 10에서 구현되었습니다(아래 단계 10 항목 참고). 경계 밖이라는 이유로 피해를 받지는 않습니다.
  - 반경 강화 데이터: 기본 반경과 강화 레벨(0~3)을 따로 관리하고 `반경 = 기본 반경 × (1 + 레벨 × 0.1)`
    (300 / 330 / 360 / 390px). 중간 보스를 처치하면 `BOUNDARY UPGRADE` 카드 화면에서 선택해 적용합니다(단계 11).
  - 경계 안에 있는 동안 무기도 강해집니다(임시): 원거리 무기는 투사체가 2발(약 8도씩 벌어져 발사), 근접(범위) 무기는 범위가 2배입니다. 값은 `BOUNDARY.projectileCountMultiplier`, `BOUNDARY.meleeRangeMultiplier`입니다.
  - 레벨 입력 처리: 숫자가 아닌 값과 NaN은 0, `Infinity`는 최대(3), `-Infinity`는 0, 소수는 버림.
  - `baseRadius`는 경계를 만들 때 정해지는 읽기 전용 값입니다(대입하면 오류). 0 이하이거나 유한하지 않은 값으로는 경계를 만들 수 없습니다.

- 일반 적 원혼 (단계 4)
  - 스프라이트: `wonyon_right_48.png`(플레이어가 오른쪽에 있을 때), `wonyon_left_48.png`(왼쪽). 두 장은 서로 다른 그림이라 한 장을 뒤집어 쓰지 않습니다.
    한 장만 불러오지 못하면 다른 한 장으로 양쪽을 대신하고(콘솔 경고), 둘 다 실패하면 임시 원형으로 표시합니다. 게임은 멈추지 않습니다.
  - 화면 바깥에서 생성되어 플레이어를 향해 이동하고, 적끼리는 서로 밀어내며(공간 격자) 월드 밖으로 나가지 않습니다. 플레이어는 적을 통과해 지나갈 수 있습니다.
  - 생성: 기본 간격/그룹 크기에서 시작해 1분마다 기본값 대비 +20%p(가산)씩 늘고, 5:00부터 신규 생성을 완전히 멈춥니다(남은 적은 계속 추적). 동시에 최대 100마리.
  - 원혼은 HP 10으로 시작하고, 피해로 HP가 0 이하가 되면 죽어서 목록에서 제거됩니다(경험치/드롭 등 보상은 없음, 단계 6).
- 플레이어 HP와 접촉 피해 (단계 5)
  - HP 바를 화면 왼쪽 아래에 표시합니다. HP가 0이 되면 즉시 게임 오버이며 부활은 없습니다.
  - 적과 닿으면(원형 판정: 플레이어 반지름 + 적 충돌 반지름 이하) 피해를 입습니다. 여러 마리가 동시에 닿아도 피해는 한 번만 적용됩니다.
  - **피격 후 보호**: 피해를 입으면 보호 시간이 시작되어 그동안 접촉 피해를 받지 않고(플레이어가 깜빡임), 끝난 뒤에도 계속 닿아 있으면 다시 피해를 입습니다.
  - **대시 무적**: 대시를 시작하면 무적 시간이 따로 시작됩니다. 피격 후 보호와는 별개의 타이머이며, 둘 중 하나라도 켜져 있으면 피해를 받지 않습니다.
    대시 무적이 끝나도 피격 후 보호가 새로 생기지는 않습니다. 일시 정지 중에는 두 타이머가 모두 멈춥니다.
  - HP 회복은 아직 없습니다. 경계 효과는 단계 10, 적 투사체 피해는 단계 7에서 추가되었습니다.
- 경험치와 레벨업 (단계 8)
  - 적이 죽으면 그 자리에 경험치 구슬이 한 개 생깁니다(일반 적 1 XP, 원거리 적 2 XP). 한 적에게서는 한 번만 생기고, 구슬은 줍거나 새 런을 시작할 때까지 월드에 남습니다.
  - 플레이어 중심에서 줍기 반경(기본 60px) 안에 구슬이 들어오면 자동으로 주워서 XP가 오릅니다. 구슬과 플레이어는 모두 월드 좌표라 카메라와 무관합니다.
  - 필요 XP: Lv1→2는 8, 이후 레벨마다 4씩 늘어납니다(8, 12, 16, 20, …). 남은 XP는 다음 레벨로 이월됩니다. 화면 왼쪽 아래에 `LV n   XP x / y`와 경험치 바가 표시됩니다.
  - **레벨업 선택 화면(보상 카드 UI, 단계 9)**: 레벨이 오르면 게임이 `levelup` 상태로 바뀌어 이동, 대시, 무기, 적, 투사체, 쿨다운, 게임 시간이 모두 멈추고, 화면 전체가 반투명하게 어두워지며 제목 `LEVEL UP`과 함께 보상 카드가 화면 중앙에 가로로 나타납니다(애니메이션 없이 즉시).
    - 카드는 최대 3장이고 후보가 1~2개면 그만큼만 보입니다. 카드 크기는 화면 크기에 따라 조절되며 최소/최대로 제한됩니다(170~240px 너비, 230~320px 높이, 아주 좁은 화면에서는 화면 밖으로 나가지 않도록 줄어듭니다).
    - 각 카드에는 왼쪽부터 선택 번호(1, 2, 3), 보상 유형(신규 무기 / 무기 강화 / 자석 강화), 이름, 효과 수치(예: `Lv.1 → Lv.2 · 피해 3 → 3.6`, `줍기 반경 60px → 66px`), 짧은 설명이 표시됩니다. 값은 모두 보상 데이터에서 그대로 가져옵니다.
    - **선택**: 키보드 **1/2/3**(숫자 키패드 포함, 화면의 왼쪽부터 센 카드 번호) 또는 **카드 영역 클릭**. 둘 다 같은 선택 함수를 쓰고, 표시되지 않은 번호나 카드 밖 클릭은 무시됩니다. 카드를 그리는 배치 계산을 클릭 판정에도 그대로 써서 그려진 영역과 클릭 영역이 일치합니다.
    - **선택 강조**: 고른 카드가 흰 굵은 테두리로 잠깐(0.15초) 강조되고 나머지는 흐려집니다. 이 동안 보상은 이미 적용되었고 게임은 계속 정지 상태이며 입력은 받지 않습니다. 강조가 끝나면 다음 화면을 열거나 전투를 재개합니다.
    - Esc/Enter/대시는 선택 중에 동작하지 않습니다. 한 번에 여러 레벨이 오르면 화면이 하나씩 열리고, 마지막 선택을 마친 뒤에만 전투가 재개됩니다. 단계 8에 있던 `남은 레벨업 n` 문구는 제목 외 추가 문구를 넣지 않는다는 기준에 따라 화면에서 뺐습니다.
    - 경계 강화 화면(`BOUNDARY UPGRADE`)은 같은 카드 코드를 제목만 바꿔 쓰며, 중간 보스 처치 시 열리도록 단계 11에서 연결되었습니다.
  - **보상 후보**(레벨업 화면마다 현재 상태로 새로 계산, 유효한 후보 중 무작위 최대 3개): 신규 무기 획득(미보유이고 슬롯이 남았을 때), 보유 무기 강화(레벨 5 미만), 경험치 자석 강화(3회 미만). 신규 무기와 무기 강화는 화면에서 `[신규 무기]`, `[무기 강화]`로 구분합니다.
    후보가 1~2개면 있는 것만 보여 주고, 하나도 없으면 화면을 열지 않고 보상 없이 건너뜁니다(재화 시스템은 아직 없음).
  - 경험치 자석: 줍기 반경 +6px씩, 최대 3회(60 → 66 → 72 → 78px). 무기 슬롯과 무기 레벨과는 별개입니다.
  - 새 런을 시작하면 구슬, XP, 레벨, 자석, 대기 중인 보상, 무기(shard만, 레벨 1), 투사체, 부메랑, 번개 효과가 모두 초기화됩니다. 게임 오버가 난 프레임에는 구슬을 줍지 않고 보상도 열리지 않습니다.
- 무기 4종과 레벨 (단계 8)
  - 시작 무기는 `shard`뿐입니다. `pulse`, `Chain Lightning`, `Boomerang Blade`는 레벨업 보상으로 얻습니다. 슬롯은 최대 3개, 종류당 하나, 최대 레벨 5입니다.
  - 무기 레벨은 **피해만** 올립니다: 피해 = 기본 피해 × (1 + 0.2 × (레벨 − 1)) = 100/120/140/160/180%. 공격 주기, 사거리, 연쇄 횟수 등은 변하지 않습니다. 소수 피해는 반올림하지 않고 그대로 적용하며(적 HP도 소수), 부동소수점 잔여값 때문에 살아남지 않도록 HP 1e-9 미만은 0으로 봅니다.
  - **Chain Lightning**(`chainLightning`): 사거리 180px 안에서 가장 가까운 적에서 시작해, 직전 적에서 100px 이내의 가장 가까운 아직 안 맞은 적으로 최대 3마리(최초 포함)까지 연쇄합니다. 적마다 피해 2, 주기 1.2초. 같은 공격에서 같은 적은 한 번만 맞고, 다음 적이 없으면 거기서 끝납니다. 지그재그 번개 선으로 잠깐 표시됩니다.
  - **Boomerang Blade**(`boomerangBlade`): 사거리 220px 안에서 가장 가까운 적을 향해 속도 300px/초로 날아가고(타깃이 살아 있으면 따라가고, 죽으면 마지막 위치로), 도달하거나 300px를 날아가면 플레이어의 **현재 위치**로 돌아옵니다. 경로상의 모든 적을 맞히며 왕복 한 번에 적마다 한 번만 맞습니다(돌아오는 길에도 안 맞은 적은 맞음). 피해 2, 주기 2초. 이동 구간 전체로 판정하고, 안전장치로 6초 안에 반드시 사라집니다. 나가는 중에는 금색, 돌아오는 중에는 청록색 마름모로 표시됩니다.
- 원거리 적과 적 투사체 (단계 7)
  - 새로 생기는 적 한 마리가 확률 25%로 원거리 적입니다. 생성 간격, 그룹 크기, 최대 수, 5:00 중단 규칙은 그대로입니다.
  - 원거리 적은 일반 원혼과 같은 스프라이트와 추적 AI를 쓰고(거리 유지 없음), 보라색 마름모와 발밑 고리로 구분합니다.
  - 플레이어가 사거리(300px) 안에 있으면 2.5초마다 투사체를 쏩니다. 생성 직후에도 2.5초가 지나야 처음 쏘며, 사거리 밖이면 쿨다운 0에서 기다렸다가 들어오면 바로 쏩니다. 죽은 적은 쏘지 못합니다.
  - 투사체는 발사 순간의 플레이어 위치로 방향을 한 번 정하고 직선으로 날아갑니다(유도 없음). 최대 350px를 날아가거나 월드 밖으로 나가면 사라집니다. 이동 구간 전체로 판정해서 느린 프레임에도 플레이어를 관통하지 않습니다.
  - 명중하면 투사체는 항상 사라지고(한 투사체는 한 번만 명중), 피해 10은 접촉 피해와 같은 규칙을 따릅니다. 피격 후 보호나 대시 무적 중이면 피해 없이 사라집니다. 투사체 피해도 피격 후 보호를 시작합니다.
  - 정지/게임 오버 중에는 투사체와 발사 쿨다운이 멈추고, 새 런을 시작하면 투사체와 모든 적이 지워져서 쿨다운도 초기화됩니다.
- 무기와 자동 공격 (단계 6)
  - 공격은 모두 자동입니다(마우스 조준 없음). 무기마다 사거리 안에서 가장 가까운 살아 있는 적(거리가 같으면 번호가 작은 적)을 골라 쿨다운이 끝날 때마다 발동합니다. 사거리 안에 적이 없으면 쿨다운 0에서 기다립니다.
  - 무기 슬롯은 최대 3개, 레벨은 최대 5, 같은 종류는 하나만 가질 수 있습니다. 획득/강화는 레벨업 보상 카드(단계 8~9)로 하며, 새 런은 `STARTING_WEAPONS`(현재 `shard` 하나)로 시작합니다.
  - 원거리 테스트 무기(`shard`): 가장 가까운 적을 향해 투사체를 발사합니다. 피해 3(원혼 4번 명중에 처치). 투사체는 적 하나를 맞히면 사라지고, 월드 밖으로 나가거나 최대 거리를 넘어도 사라집니다. 한 프레임에 이동한 선분 기준으로 판정해서 느린 프레임에도 적을 뚫고 지나가지 않습니다.
  - 근접 테스트 무기(`pulse`): 플레이어 중심 반경 안의 모든 적을 한 번씩 때립니다. 피해 5(원혼 2번에 처치). 발동하면 고리 효과가 잠깐 보입니다.
  - 정지/게임 오버 중에는 무기 갱신 자체를 하지 않아 쿨다운, 투사체, 효과가 모두 멈춥니다. 새 런을 시작하면 투사체와 효과를 지우고 무기 쿨다운/레벨을 초기화합니다.
  - 죽은 적은 같은 프레임에 목록에서 제거되어 이후 대상 선택, 공격, 이동, 밀어내기, 접촉 피해, 적 수 계산에서 빠집니다.

좌표 변환: `screen = world - camera`, `world = screen + camera` (`camera`는 화면 왼쪽 위가 가리키는 월드 좌표).

## 로비와 모바일 (로비 MVP, docs/LOBBY_MVP_PLAN.md)

- 흐름: 로비 → 던전 선택(카드 2장, 선택하면 강조, 입장 버튼) → 전투 → 결과 → 다시 도전/로비. 입장은 무료이고 횟수 제한이 없습니다.
- 던전: "폐허가 된 조선"(확정 이름), 두 번째는 가칭 "저승길 어귀"(준비 중, 입장 불가).
- 재화: 엽전(영구 업그레이드용)과 이름 조각(도감 이름 등록용). 지급량, 업그레이드 효과/비용, 업적, 몬스터 이름은 모두 **[임시]** 제안값입니다.
- 저장: 브라우저 localStorage(키 `ninefold-veil-save`). 새로고침해도 유지되고, 손상되면 기본값으로 시작하며 원본은 백업 키에 남깁니다. 설정에서 내보내기/가져오기(검증 + 덮어쓰기 확인)와 초기화(확인 필수)를 할 수 있습니다.
- 모바일(가로 화면): 터치 기기에서는 왼쪽 아래 가상 조이스틱(8방향)과 오른쪽 아래 대시 버튼이 나타납니다. 자동 공격은 기존 시스템 그대로이고, 능동 스킬이 없어 스킬 버튼은 없습니다. PC에서 확인하려면 주소 끝에 `?touch=1`을 붙이세요. 일시 정지/포기는 전투 화면 위쪽 버튼으로 합니다.
- 개발 주소의 `?t=115`, `?speed=10`은 전투 화면에서 그대로 동작합니다(로비에서 입장한 뒤 적용).

## 개발용 테스트 기능 (`npm run dev`에서만 동작, 빌드에서는 제거됨)

- `?t=115` 게임 시간을 115초부터 시작 (예: `http://localhost:5173/?t=115`)
- `?speed=10` 게임 시간만 10배 빠르게 (이동/대시 속도는 그대로)
- `G` 키: 게임 오버 강제 발생
- `B`: 경계 내구도 -10%, `Shift+B`: 전부 깎음. 화면에 내구도와 회복 상태 표시
- 화면 왼쪽 위에 플레이어/카메라 월드 좌표와 경계 안/밖 상태(`boundary: inside (d=거리 / r=반경)`) 표시
- 월드 좌표 200px 간격 교차점마다 작은 십자 표시(화면에 보이는 영역만 그림)
- 월드 중앙 십자와 월드 외곽선(붉은 테두리) 표시
- `X`: 경험치 +10, `Shift+X`: 경험치 +100(여러 레벨 연속 레벨업 시험). 실행 중에만 동작하고 프로덕션 빌드에는 포함되지 않습니다(자동 테스트로 확인).
- 자석 레벨/줍기 반경, 구슬 수, 부메랑 수 표시
- 적 투사체 수(`enemy projectiles: N`) 표시
- 보유 무기의 레벨/쿨다운과 날아가는 투사체 수(`weapons: shard Lv1 cd 0.30 | pulse Lv1 cd 0.00  projectiles: 2`) 표시
- 현재 적 수(`enemies: N / 100`)와 플레이어 HP/보호 남은 시간/대시 무적 남은 시간(`hp: 90 / 100  protect: 0.52  dashInv: 0.00`) 표시

## 개발 진행 상황

기획 문서 12장의 단계 기준입니다. 한 단계를 검수하고 확인받은 뒤 다음 단계로 넘어갑니다.

- [x] 단계 0: 프로젝트 상태 확인 및 안전장치 (README 정리)
- [x] 단계 1: 최소 게임 화면과 시간 루프 (시간, 상태, Esc 일시 정지)
- [x] 단계 2: 플레이어 이동과 카메라 (월드 좌표)
- [x] 단계 3: 원형 경계 기본형
- [x] 단계 4: 적 생성, 추적, 충돌 (직접 플레이 검증 완료)
- [x] 단계 5: 플레이어 HP, 접촉 피해, 대시 무적 (사용자 검수 완료)
- [x] 단계 6: 자동 공격과 기본 무기 (사용자 검수 완료)
- [x] 단계 7: 원거리 적 투사체 (사용자 검수 완료)
- [x] 단계 8: 경험치 구슬과 레벨업 (사용자 검수 완료)
- [x] 단계 9: 공통 보상 카드 UI (사용자 검수 완료)
- [x] 단계 10: 경계 내구도와 강화 효과 (사용자 검수 완료)
  - 경계 내구도(최대 100, 0이어도 파괴되지 않음), **R 키**로 회복 ON/OFF(기본 ON), 마지막 피해 3초 뒤부터 초당 최대 내구도의 5% 회복. 개발 모드에서 **B 키**는 내구도 -10%, Shift+B는 전부 깎음.
  - 내구도 손실 10%마다 경계 버프 5% 약화(최대 50%). 임시 버프: 경계 안 플레이어 공격력 +50%(약화 적용). 인간형 적/보스는 버프의 50%만 공유(현재 인간형 적은 없음), 경계 밖은 받지 않음.
  - 경계 반경 강화(레벨당 +10%, 최대 390) 후보/적용 로직 구현(화면 연결은 단계 11). 보스는 표시 크기 110%(표시만 적용).
  - 새 파일: `src/boundaryBuffs.js`, `src/boundaryRewards.js`, `tests/boundary*.test.js`.
- [x] 단계 11: 중간 보스 (사용자 검수 완료)
  - 2:00에 중간 보스가 플레이어에게서 800px 떨어진 화면 밖에 한 번 출현(보스/정예 같은 특수 적은 공통으로 이 규칙을 따름. 월드 가장자리에서 잘리거나 화면 안에 들어오면 다른 방향을 찾음. HP 200, 속도 80, 크기 110%, 금색 고리와 HP 바 — 모두 [임시]). 일반 적과 같은 이동/접촉 피해/무기 피해 규칙을 쓰며 새 공격은 없음.
  - 처치하면 `BOUNDARY UPGRADE` 카드 화면이 열려 전투와 시간이 멈추고, 1~3 키/클릭으로 반경 강화를 한 번 적용(현재 후보는 반경 강화 1장뿐). 레벨업과 겹치면 경계 강화가 먼저 열리고 이어서 레벨업 화면이 열림.
  - 새 파일: `src/boss.js`, `tests/miniBoss.test.js`. 보상 흐름은 `createRewardFlow`로 일반화.
- [x] 단계 12: 최종 보스와 런 종료 (사용자 검수 완료, 이후 사용자 결정으로 시간표 변경)
  - **두 번째 보스(3:00)**: HP 400, 속도 80. 처치해도 승리하지 않고 보상도 없으며 런은 계속됩니다. 중간 보스 생존 여부와 무관하게 한 번만 나옴.
  - **최종 보스(5:00)**: HP 800, 속도 80, 새 공격 없음 — `config.js`의 `BOSS.finalBoss`, 모두 [임시]. 다른 보스의 생존 여부와 무관하게 한 번만 나옴. 처치하면 승리하는 보스는 이 보스뿐입니다.
  - 최종 보스를 처치하면 즉시 `victory` 상태: 시간, 적 생성/이동, 투사체, 쿨다운, 입력이 모두 멈추고 승리 문구와 생존 시간, Enter 안내만 남음. Enter로 새 런 시작. 같은 프레임에 플레이어가 죽으면 게임 오버가 우선.
  - 아직 열지 않은 보상 예약은 승리 시 지워 보상 화면이 다시 열리지 않음(이미 적용된 보상은 그대로). 5:00에도 런은 끝나지 않고 일반 적 생성만 멈춤.
  - 새 파일: `tests/finalBoss.test.js`.
- [x] 단계 13: 5분 수직 슬라이스 검수 (자동 검수와 사용자 수동 검수 완료)
  - 자동 검수: 자동 테스트 195/195 통과, 빌드 성공. 새 파일 `tests/verticalSlice.test.js`(6분 연속 시뮬레이션, 적 생성 증가, 5:00 이후 계속 진행, 재현성, 프레임 CPU 시간/누적 객체).
  - 시뮬레이션 결과: 보스 출현 2:00/3:00 확인, 분당 적 생성 60 → 88 → 118 → 154마리, 5:00 이후 신규 생성 없음, 동시 적 최대 73마리. 프레임 CPU 시간은 평균 약 0.14ms(가짜 그리기 컨텍스트 기준, **실제 화면 렌더링 성능은 측정하지 않음**).
  - 사용자 수동 검수: 성공. 자동 시뮬레이션의 한계(제자리에서 HP를 채우는 조건이라 조작감, 난이도, 렌더링 성능은 반영되지 않음)는 이 수동 검수로 보완했습니다. 후보 최대 수(3)가 코드 여러 곳에 중복된 점은 알려진 사항으로 남겨 둡니다.

이번 수직 슬라이스에서 제외: 동료 수집, 도감, 무한 복합 영역, 건물 파괴, 무기 진화, 모바일 조작, 스토리 캠페인, 최종 아트.
